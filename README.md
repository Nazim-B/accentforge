# AccentForge — веб-версия (PWA), Phase 1

## Что это

Полноценное веб-приложение: HTML/CSS/JS, без сборщиков и фреймворков. Все данные
(книги, аудио, ваши записи, статистика) хранятся локально в браузере через IndexedDB —
ничего не уходит на сервер, интернет нужен только один раз при первом открытии
(и при обновлении версии), дальше работает офлайн.

Я проверил синтаксис всех JS-файлов (`node --check`), но **не тестировал в реальном
браузере** — здесь у меня его нет. IndexedDB, MediaRecorder и Web Audio API в Safari на
iOS исторически имеют свои особенности, поэтому первый прогон на вашем iPhone — обязательный
шаг, не формальность.

## Как разместить (нужен HTTPS для PWA — localhost и file:// не подходят для полноценной установки)

Рекомендую **GitHub Pages** — бесплатно, надёжно, не требует ничего кроме GitHub-аккаунта:

1. Зайдите на github.com, создайте новый репозиторий (например `accentforge`), публичный.
2. Загрузите туда содержимое папки `AccentForgeWeb/` целиком (через веб-интерфейс: "Add file" → "Upload files" — можно перетащить всю папку, либо через `git push`, если знакомы с git).
3. В репозитории: Settings → Pages → Source → выберите ветку `main` и папку `/ (root)` → Save.
4. Через 1–2 минуты приложение будет доступно по адресу вида `https://<ваш-логин>.github.io/accentforge/`.
5. Откройте эту ссылку в **Safari** на iPhone (обязательно Safari, не Chrome — только Safari умеет добавлять PWA на домашний экран на iOS).
6. Кнопка "Поделиться" (квадрат со стрелкой вверх) → "На экран «Домой»" → Добавить.
7. Дальше открывайте приложение с иконки на домашнем экране — оно будет работать в полноэкранном режиме, как обычное приложение, и офлайн.

Альтернатива без GitHub-аккаунта: [Netlify Drop](https://app.netlify.com/drop) — перетаскиваете папку прямо в браузере, получаете ссылку сразу. Минус: без аккаунта ссылка может быть менее долговечной; для постоянного использования GitHub Pages надёжнее.

## Важный риск, о котором нужно знать заранее

**Safari на iOS может удалять локальные данные сайта (включая IndexedDB), если приложением не пользовались около 7 дней подряд.** Это касается и PWA, установленных на домашний экран — они не полностью защищены от этой политики, хотя обычно живут дольше, чем данные в обычной вкладке. Практический вывод:
- Для ежедневной практики (а именно так задумано приложение) риск минимален.
- Если планируете перерыв дольше недели — на будущее стоит добавить функцию экспорта/бэкапа записей и разметки книг (в Phase 1 её нет, это первый кандидат в Phase 2).

## Что реализовано (соответствует Swift-версии Phase 1)

- Импорт своего аудиофайла + PDF/TXT текста.
- Автоматическое предложение границ фрагментов по паузам (энергетический анализ через Web Audio API).
- Ручное подтверждение/правка границ + вставка текста на каждый фрагмент, с панелью "Текст книги" для сверки (PDF парсится локальным pdf.js, без интернета).
- Shadowing: A–B loop, скорость 0.5×–1.25× (браузер сохраняет высоту тона автоматически — искажений быть не должно).
- Запись голоса через микрофон (MediaRecorder), привязка к книге/фрагменту/дате.
- Список записей с воспроизведением и удалением.
- Банк упражнений для разминки с ежедневной ротацией.
- Простая статистика: серия дней, время практики, фрагменты.
- Работает офлайн после первого открытия (service worker кэширует всё приложение).

## Что сознательно не реализовано (см. ТЗ v2)

- Экспорт/бэкап данных — из-за риска очистки Safari это стоит добавить раньше, чем в Swift-версии; отметил как первую задачу Phase 2.
- Автоматическое разбиение PDF-текста по фрагментам — вставляете вручную.
- Определение глав — вся книга одна "Глава 1".
- Сравнение записей бок о бок — только переключение между вкладками.

## Что проверить в первую очередь на реальном iPhone

1. **Разрешение на микрофон** — при первой записи Safari спросит доступ; если случайно отклонить, включить обратно можно в Настройки iOS → Safari → (или через настройки конкретного сайта).
2. **Импорт длинного аудиофайла** — `AudioSegmenter` декодирует весь файл в память через Web Audio API; для многочасовой аудиокниги целиком это может быть медленно или упереться в память браузера. Начните с одной главы (10–30 минут), не с книги целиком.
3. **Пороги тишины** — если границы фрагментов после импорта окажутся слишком частыми или слишком редкими на реальной записи Фрая, правьте `AF.AudioSegmenter.config` в `js/segmenter.js` (`silenceThreshold`, `minSilenceDuration`).
4. **Формат записи** — на iOS Safari запись сохраняется в `audio/mp4`; если при воспроизведении своей записи будет тишина или ошибка — пришлите мне, это первое место для проверки.
5. Установка на домашний экран и повторное открытие оттуда — что приложение действительно открывается без интернета (например, включите авиарежим и откройте иконку).

Если что-то не заработает — пришлите мне точный текст ошибки (можно посмотреть через Safari → Настройки → Дополнения → Web Inspector, если подключить iPhone к Mac; либо просто опишите, на каком шаге и что произошло) — поправлю сразу.
